⚡ Álgebra de Boole: Corazón del Hardware

Las variables booleanas (0/1) representan señales eléctricas. Las funciones booleanas se implementan con puertas lógicas (AND, OR, NOT). Cada operación que realiza un procesador (suma, resta, comparación) se descompone en operaciones booleanas. La simplificación de expresiones booleanas conduce a circuitos más rápidos, baratos y eficientes energéticamente.

Objetivo: dominar el álgebra de Boole y entender cómo construye desde una compuerta hasta un microprocesador.

Variables booleanas · 0 / 1

Una variable booleana sólo puede ser 0 (falso, 0V) o 1 (verdadero, +5V). Las operaciones fundamentales son:

  • AND (·): 1·1 = 1, resto 0
  • OR (+): 0+0=0, resto 1
  • NOT (¬): ¬0=1, ¬1=0

Hardware: señal eléctrica

En un circuito digital, '0' suele ser 0 voltios, '1' es +5V o +3.3V. Las compuertas son transistores que conmutan.

Relación con hardware: Cada variable booleana es un bit. Un byte son 8 variables. Los buses de datos transmiten estas señales.

Tablas de verdad · Función booleana

Una función booleana toma n variables (entradas) y produce una salida que se puede representar en una tabla de verdad.

Simplificación de expresiones booleanas

Usa leyes: A+0=A, A·1=A, A+Ā=1, A·Ā=0, DeMorgan, etc. También método de Karnaugh (mapas K) para hasta 4 variables.

Leyes importantes

  • Idempotencia: A·A = A, A+A = A
  • Absorción: A + A·B = A
  • DeMorgan: ¬(A·B) = ¬A + ¬B

✅ Una expresión más simple ⇒ menos compuertas ⇒ menor costo, menor consumo, mayor velocidad en el procesador.

ALU: La unidad aritmético-lógica

La ALU del procesador realiza operaciones booleanas y aritméticas usando puertas lógicas. Por ejemplo, una suma de 4 bits se construye con medio sumador y sumadores completos (XOR, AND, OR).

Optimización de código fuente

Las condiciones complejas en lenguajes (if, while) pueden simplificarse usando álgebra de Boole, mejorando legibilidad y rendimiento.

Ejemplo JavaScript

// Código original:
if ((x > 0 && y > 0) || (x > 0 && y <= 0)) { ... }

// Simplificado aplicando álgebra booleana: 
// (x>0) && (y>0 || y<=0) ≡ (x>0) && True ≡ x>0
if (x > 0) { ... }

✅ Compiladores también realizan estas optimizaciones usando leyes booleanas (reducción de saltos condicionales).
