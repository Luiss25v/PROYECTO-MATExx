⚡ Álgebra de Boole → Hardware real

Las variables booleanas (0/1) representan voltajes. Las puertas lógicas (AND, OR, NOT) construyen circuitos. Un procesador ejecuta operaciones usando ALU que implementa suma, resta, comparaciones mediante álgebra booleana. Simplificar funciones booleanas = menos compuertas = más rápido y eficiente.

¿Cómo funciona?

La suma se implementa con sumadores completos usando XOR, AND y OR. La resta se hace con complemento a dos (NOT + suma). Las operaciones lógicas son directas.

⚙️ Optimización de código con álgebra booleana

if ((x > 0 && y > 0) || (x > 0 && y <= 0)) → aplicando álgebra: (x>0) && (y>0 || y<=0) ≡ (x>0) && true ≡ x>0
