    FUNCIONES BOOLEANAS

    MISIÓN 2

    1. DEFINICIÓN

    Una función booleana asigna valores 0/1 a cada combinación de sus variables de entrada.

    f(A,B,C) = Σ(m₁, m₂, m₅, m₇)

    2. FORMAS CANÓNICAS

    Minterms: producto de variables que da 1 en una sola fila.
    Maxterms: suma que da 0 en una sola fila.

    Ejemplo: f(A,B,C) = Σm(1,2,5,7) → A'B'C + A'BC' + AB'C + ABC

    SIMPLIFICACIÓN

    MISIÓN 3

    1. LEYES DEL ÁLGEBRA DE BOOLE

    • Idempotencia: A + A = A, A·A = A
    • Complemento: A + ¬A = 1, A·¬A = 0
    • De Morgan: ¬(A·B) = ¬A + ¬B, ¬(A+B) = ¬A·¬B
    • Distributiva: A·(B+C) = A·B + A·C

    2. MAPAS DE KARNAUGH
